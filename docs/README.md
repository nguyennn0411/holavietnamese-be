# Backend documentation

Tài liệu backend được đặt chung tại đây để thư mục gốc chỉ giữ các entrypoint của dự án.

- `DEMO_DATA.md`: nạp dữ liệu demo và course mẫu.
- `MYSQL_DOCKER.md`: chạy MySQL và backend bằng Docker.
- `COURSE_IMPORT.md`: import khóa học từ Excel.
- `LEARNER_FEATURES.md`: API và luồng học viên.
- `FOUNDATION_CURRICULUM.md`, `PRONUNCIATION_COURSE.md`, `CHAPTER_*_COURSE.md`: nội dung chương trình học.
- `TV123_COURSES.md`, `TV123_PACKAGE_COURSES.md`: bộ khóa học TV123.
- `INTEGRATION_DEMO.md`: lưu ý tích hợp và lịch sử migration.
- `CLOUDINARY_AUDIO.md`: quy trình media/audio.

Các lệnh trong tài liệu được viết để chạy từ thư mục gốc `BE`.
